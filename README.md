# Simple-Tools

A collection of lightweight, minimalist micro-tools built using AI to automate repetitive tasks, save time, and inspire builders to create their own tools.

Everything here was **vibe-coded**—leveraging AI to rapidly turn ideas into working software without getting bogged down in boilerplate code.
