خارطة الطريق لربط «مرجع» بـ Google Drive

ثماني خطوات واضحة تأخذك من الصفر إلى المزامنة السحابية الكاملة. اتبع الخطوات بالترتيب، وضع علامة على كل خطوة تنجزها.

1
الخطوة الأولى

إنشاء مشروع على Google Cloud

المشروع هو الحاوية التي ستضم كل إعدادات الربط. كل حساب Google يقدر ينشئ عددًا غير محدود من المشاريع مجانًا.

  • افتح console.cloud.google.com وسجّل الدخول بحسابك.
  • في أعلى الصفحة، اضغط على قائمة المشاريع ثم اختر مشروع جديد (New Project).
  • أدخل اسمًا للمشروع، مثلًا: maraje3 ثم اضغط إنشاء.
  • تأكد من اختيار المشروع الجديد في الشريط العلوي.

ملاحظة: اختر اسمًا تعرفه لاحقًا، فالاسم سيظهر في كل صفحات الإعداد القادمة.

2
الخطوة الثانية

تفعيل Google Drive API

Google لا تسمح لأي تطبيق بالوصول إلى Drive افتراضيًا. يجب أن تفعّل الـ API يدويًا لكل مشروع.

  • من القائمة الجانبية، اختر APIs & Services ثم Library.
  • في خانة البحث اكتب: Google Drive API.
  • اضغط على النتيجة ثم اضغط زر Enable (تفعيل).
  • انتظر حتى تظهر رسالة نجاح التفعيل.

قد يستغرق التفعيل نصف دقيقة. عندما يظهر تاريخ ووقت آخر تفعيل، فقد نجحت.

3
الخطوة الثالثة

إعداد شاشة الموافقة (OAuth Consent Screen)

هذه الشاشة هي التي ستظهر للمستخدم عند تسجيل الدخول، وتحدد ما يريد التطبيق الوصول إليه.

  • اذهب إلى APIs & Services ثم OAuth consent screen.
  • اختر نوع المستخدم External ثم اضغط Create.
  • املأ الاسم وبريدك الإلكتروني، ثم أكمل الخطوات.
  • في قسم Scopes أضف النطاق التالي:

https://www.googleapis.com/auth/drive.file

  • في قسم Test users أضف بريدك الإلكتروني (نفس البريد الذي ستسجل الدخول به).
  • اضغط Save and Continue حتى النهاية.

خطأ شائع: نسيان إضافة بريدك في Test users سيؤدي إلى خطأ 403: access_denied لاحقًا.

4
الخطوة الرابعة

إنشاء Client ID

هذا المعرّف هو ما يعرّف Google بتطبيقك، وهو المفتاح الأول الذي ستضعه داخل الأداة.

  • اذهب إلى APIs & Services ثم Credentials.
  • اضغط Create Credentials واختر OAuth client ID.
  • Application type: اختر Web application.
  • Name: اكتب Marja3 Web.
  • أضف عناوين JavaScript المصرّح بها (حسب مكان تشغيل الأداة).
  • اضغط Create وانسخ Client ID.
تشغيل محلي
http://localhost http://127.0.0.1
GitHub Pages
https://username.github.io

اكتب النطاق فقط، بدون شرطة مائلة في النهاية، وبدون اسم المستودع.

5
الخطوة الخامسة

إنشاء API Key

المفتاح الثاني. هذا يسمح للأداة باستدعاء خدمات Google دون الحاجة إلى تفويض مستخدم في كل مرة.

  • في صفحة Credentials، اضغط Create Credentials ثم اختر API key.
  • انسخ المفتاح الظاهر.
  • (اختياري) من Edit API key قيّد المفتاح بـ Google Drive API فقط لمزيد من الأمان.
6
الخطوة السادسة

إدخال المفاتيح داخل أداة «مرجع»

الآن ننتقل من Google Cloud إلى الأداة نفسها.

  • افتح أداة «مرجع» في المتصفح.
  • اضغط زر الترس في الشريط العلوي لفتح الإعدادات.
  • الصق Client ID في الحقل الأول، وAPI Key في الحقل الثاني.
  • اضغط حفظ المفاتيح.

المفاتيح تُحفظ في متصفحك فقط (LocalStorage)، ولا تُرسل إلى أي خادم غير Google.

7
الخطوة السابعة

الاتصال بـ Google والموافقة

هنا ستظهر لك شاشة Google التي أعددتها مسبقًا للموافقة على الصلاحيات.

  • في نافذة الإعدادات، اضغط الاتصال بـ Google.
  • اختر حسابك من النافذة المنبثقة.
  • إذا ظهرت شاشة «Google hasn't verified this app»، اضغط Advanced ثم Go to Marja3 (unsafe).
  • اضغط Continue / Allow للموافقة على الصلاحية.

رسالة "غير موثّق" طبيعية لأن تطبيقك خاص بك وليس منشورًا للعموم. اضغط "Advanced" وتابع.

8
الخطوة الثامنة

المزامنة والتحقق

الخطوة الأخيرة. بعد هذه، كل شيء سيعمل تلقائيًا.

  • اضغط زر مزامنة في الشريط العلوي.
  • انتظر ظهور رسالة «تم إنشاء نسخة احتياطية على Drive».
  • افتح Google Drive وابحث عن ملف references_backup.json للتأكد.

لن يظهر الملف في «ملفاتي» إلا بعد أول عملية رفع، وهذا طبيعي. استخدم البحث في Drive للتأكد.

الخلاصة السريعة

  1. أنشئ مشروعًا على Google Cloud.
  2. فعّل Google Drive API.
  3. أعدّ OAuth Consent Screen وأضف النطاق وبريدك.
  4. أنشئ OAuth Client ID (نوع Web).
  5. أنشئ API Key.
  6. الصق المفتاحين في إعدادات الأداة.
  7. اضغط الاتصال بـ Google ووافق.
  8. اضغط مزامنة، وانتهى الأمر.
