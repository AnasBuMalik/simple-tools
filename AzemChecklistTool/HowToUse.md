# Azem Checklist Tool - How to Use

This is a lightweight, single-file HTML utility designed to speed up attendance logging for the Azem Foundation and simplify exporting data to Excel.

## How to Run
No installation or setup is required!
1. Double-click the index.html (or the tool's HTML file) to open it in any web browser (Chrome, Firefox, Safari, Edge).
2. Alternatively, right-click the file and choose Open With > [Your Browser].

## Notes
- Please turn off the screen's Virtual Keyboard for the tool to work efficiently and without issues, as there is already a built-in keyboard included within the application.
- Since this tool is open and vibe-coded, you can easily customize it by feeding the file into any AI model (like Claude, ChatGPT, or Cursor) and describing the specific changes you want. This is highly recommended to tailor the experience to your exact needs.

## Customization
Since this tool is built under the CC0 license, you can open the HTML file in any text editor (like Notepad or VS Code) to manually change the names, styling, or logo to fit your needs.
