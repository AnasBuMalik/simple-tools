💡
هل أحتاج لهذا الدليل فعلاً؟
الأداة تعمل بدون أي إعداد وتخزّن تقدمك على جهازك فقط. لكن لتشارك تقدمك مع مجموعتك وتزامن البيانات بين أجهزتك — تحتاج لربط خادم Google Sheets، وهذه الخطوات تشرح ذلك.
📌
ما ستحتاجه:
  • حساب Google (Gmail) — أي حساب مجاني يكفي
  • متصفح حديث (Chrome، Safari، Firefox، Edge)
  • ملف index.html الخاص بالتطبيق (جاهز على جهازك)

١ أنشئ جدول Google Sheets ~ ٣٠ ثانية

  1. افتح sheets.new في متصفحك (سيُنشئ جدولاً جديداً فوراً).
  2. اضغط على اسم الجدول في الأعلى وسمِّه: حافظ - قاعدة البيانات.
  3. اترك الجدول مفتوحاً — سنعود إليه بعد قليل. لا تحتاج لإنشاء أوراق يدوياً، الخادم سيفعل ذلك تلقائياً.
ℹ️
إذا طلب منك Google تسجيل الدخول — سجّل بحسابك المعتاد، فهو من سيستضيف بياناتك.

٢ افتح محرر Apps Script ~ ٢٠ ثانية

  1. من داخل الجدول، اضغط من القائمة العلوية على Extensions ← Apps Script.
  2. ستُفتح نافذة جديدة فيها محرر أكواد. احذف كل المحتوى الموجود فيه (عادة يكون دالة فارغة اسمها myFunction).
  3. اضغط على Untitled project أعلى الصفحة وأعطه اسماً: Hafiz Backend.
⚠️
لا تغلق تبويب الجدول. سنحتاجه في الخطوات القادمة.

٣ الصق كود الخادم ~ ٦٠ ثانية

انسخ الكود التالي بالكامل والصقه في محرر Apps Script (استبدل أي شيء موجود):

HafizBackend.gs 
/**
 * ═══════════════════════════════════════════════════════════════
 *  حافظ — الخادم الخلفي (Google Apps Script)
 * ═══════════════════════════════════════════════════════════════
 */
const CONFIG = {
  USERS_SHEET: 'Users',
  PAGES_SHEET: 'Pages',
  LOG_SHEET:   'SyncLog',
  VERSION:     '1.0.0',
  LOCK_TIMEOUT_MS: 20000,
  MAX_PAGES:   604
};

function doGet(e)  { return route_(e, null); }
function doPost(e) {
  let body = null;
  try { body = JSON.parse(e.postData.contents); }
  catch (err) { return json_({ ok: false, error: 'Invalid JSON body' }); }
  return route_(e, body);
}

function route_(e, body) {
  const params = (e && e.parameter) || {};
  const action = (body && body.action) || params.action || 'ping';
  try {
    switch (action) {
      case 'ping': return handlePing_();
      case 'pull': return handlePull_(body ? body.user : params.user);
      case 'push': return handlePush_(body);
      default:     return json_({ ok: false, error: 'Unknown action: ' + action });
    }
  } catch (err) {
    logError_(action, err);
    return json_({ ok: false, error: String((err && err.message) || err) });
  }
}

function handlePing_() {
  return json_({ ok: true, app: 'حافظ', version: CONFIG.VERSION, time: new Date().toISOString() });
}

function handlePull_(username) {
  if (!username) return json_({ ok: false, error: 'Missing username' });
  const usersSheet = getUsersSheet_();
  const pagesSheet = getPagesSheet_();
  const uname = String(username).toLowerCase();
  const usersData = usersSheet.getDataRange().getValues();
  let userRow = null;
  for (let i = 1; i < usersData.length; i++) {
    if (String(usersData[i][0]).toLowerCase() === uname) {
      userRow = { rowIdx: i + 1, data: usersData[i] };
      break;
    }
  }
  if (!userRow) {
    return json_({
      ok: true,
      user: { username: String(username), pages: {}, activity: {}, stats: {} },
      members: collectMembers_(usersData, pagesSheet, uname)
    });
  }
  const pages = {};
  const pagesData = pagesSheet.getDataRange().getValues();
  for (let i = 1; i < pagesData.length; i++) {
    const r = pagesData[i];
    if (String(r[0]).toLowerCase() !== uname) continue;
    pages[String(r[1])] = {
      state:        String(r[2] || 'none'),
      lastReviewed: r[3] ? new Date(r[3]).getTime() : null,
      updatedAt:    r[4] ? new Date(r[4]).getTime() : null
    };
  }
  return json_({
    ok: true,
    user: {
      username: String(userRow.data[0]),
      pages: pages,
      activity: safeParse_(userRow.data[2], {}),
      stats: safeParse_(userRow.data[3], {})
    },
    members: collectMembers_(usersData, pagesSheet, uname)
  });
}

function handlePush_(body) {
  if (!body || !body.user) return json_({ ok: false, error: 'Missing user' });
  const lock = LockService.getScriptLock();
  try { lock.waitLock(CONFIG.LOCK_TIMEOUT_MS); }
  catch (e) { return json_({ ok: false, error: 'Server busy, please retry' }); }
  try {
    const username = String(body.user).trim();
    if (!username) return json_({ ok: false, error: 'Empty username' });
    const pages = body.pages || {};
    const activity = body.activity || {};
    const stats = body.stats || {};
    const now = new Date();
    const usersSheet = getUsersSheet_();
    const pagesSheet = getPagesSheet_();
    const usersData = usersSheet.getDataRange().getValues();
    let userRowIdx = -1;
    for (let i = 1; i < usersData.length; i++) {
      if (String(usersData[i][0]).toLowerCase() === username.toLowerCase()) {
        userRowIdx = i + 1; break;
      }
    }
    if (userRowIdx === -1) {
      usersSheet.appendRow([username, '', JSON.stringify(activity), JSON.stringify(stats), now, now]);
    } else {
      const created = usersData[userRowIdx - 1][4] || now;
      usersSheet.getRange(userRowIdx, 3, 1, 4).setValues([[
        JSON.stringify(activity), JSON.stringify(stats), created, now
      ]]);
    }
    const written = rewritePagesForUser_(pagesSheet, username, pages, now);
    return json_({ ok: true, saved: true, pagesWritten: written, time: now.toISOString() });
  } finally { lock.releaseLock(); }
}

function rewritePagesForUser_(sheet, username, pages, now) {
  const uname = username.toLowerCase();
  const data = sheet.getDataRange().getValues();
  const others = [];
  for (let i = 1; i < data.length; i++) {
    if (String(data[i][0]).toLowerCase() !== uname) others.push(data[i]);
  }
  const mine = [];
  const pageNums = Object.keys(pages).map(Number)
    .filter(p => p >= 1 && p <= CONFIG.MAX_PAGES).sort((a, b) => a - b);
  for (const p of pageNums) {
    const pg = pages[p];
    if (!pg || pg.state === 'none' || !pg.state) continue;
    mine.push([
      username, p, pg.state,
      pg.lastReviewed ? new Date(pg.lastReviewed) : '',
      pg.updatedAt ? new Date(pg.updatedAt) : now
    ]);
  }
  const all = others.concat(mine);
  if (data.length > 1) sheet.getRange(2, 1, data.length - 1, 5).clearContent();
  if (all.length > 0) sheet.getRange(2, 1, all.length, 5).setValues(all);
  return mine.length;
}

function collectMembers_(usersData, pagesSheet, excludeUsername) {
  const pagesData = pagesSheet.getDataRange().getValues();
  const pagesByUser = {};
  for (let i = 1; i < pagesData.length; i++) {
    const r = pagesData[i];
    const uname = String(r[0]).toLowerCase();
    if (!uname) continue;
    if (excludeUsername && uname === excludeUsername) continue;
    if (!pagesByUser[uname]) pagesByUser[uname] = {};
    pagesByUser[uname][String(r[1])] = {
      state: String(r[2] || 'none'),
      lastReviewed: r[3] ? new Date(r[3]).getTime() : null,
      updatedAt: r[4] ? new Date(r[4]).getTime() : null
    };
  }
  const members = [];
  for (let i = 1; i < usersData.length; i++) {
    const r = usersData[i];
    const uname = String(r[0]);
    if (!uname) continue;
    if (excludeUsername && uname.toLowerCase() === excludeUsername) continue;
    members.push({
      id: 'u_' + uname, name: uname, color: colorFromName_(uname),
      pages: pagesByUser[uname.toLowerCase()] || {},
      activity: safeParse_(r[2], {})
    });
  }
  return members;
}

function json_(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
function safeParse_(str, fallback) {
  if (str === null || str === undefined || str === '') return fallback;
  if (typeof str === 'object') return str;
  try { return JSON.parse(str); } catch (e) { return fallback; }
}
function colorFromName_(name) {
  const palette = ['#60a5fa','#f472b6','#34d399','#fbbf24','#a78bfa','#22d3ee','#fb923c','#4ade80'];
  let h = 0;
  for (let i = 0; i < name.length; i++) h = (h * 31 + name.charCodeAt(i)) | 0;
  return palette[Math.abs(h) % palette.length];
}
function getSS_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  if (!ss) throw new Error('Script not bound to a spreadsheet');
  return ss;
}
function getUsersSheet_() {
  const ss = getSS_();
  let sh = ss.getSheetByName(CONFIG.USERS_SHEET);
  if (!sh) sh = createUsersSheet_(ss);
  return sh;
}
function getPagesSheet_() {
  const ss = getSS_();
  let sh = ss.getSheetByName(CONFIG.PAGES_SHEET);
  if (!sh) sh = createPagesSheet_(ss);
  return sh;
}
function getLogSheet_() {
  const ss = getSS_();
  let sh = ss.getSheetByName(CONFIG.LOG_SHEET);
  if (!sh) {
    sh = ss.insertSheet(CONFIG.LOG_SHEET);
    sh.getRange(1, 1, 1, 3).setValues([['Time','Action','Error']]);
    sh.getRange(1, 1, 1, 3).setFontWeight('bold');
    sh.setFrozenRows(1);
  }
  return sh;
}
function createUsersSheet_(ss) {
  const sh = ss.insertSheet(CONFIG.USERS_SHEET);
  sh.getRange(1, 1, 1, 6).setValues([['Username','PIN','Activity','Stats','Created','Updated']]);
  sh.getRange(1, 1, 1, 6).setFontWeight('bold').setBackground('#1e293b').setFontColor('#f5c451');
  sh.setFrozenRows(1);
  sh.setColumnWidth(1, 200);
  sh.setColumnWidth(3, 320);
  sh.setColumnWidth(4, 320);
  return sh;
}
function createPagesSheet_(ss) {
  const sh = ss.insertSheet(CONFIG.PAGES_SHEET);
  sh.getRange(1, 1, 1, 5).setValues([['Username','Page','State','LastReviewed','UpdatedAt']]);
  sh.getRange(1, 1, 1, 5).setFontWeight('bold').setBackground('#1e293b').setFontColor('#f5c451');
  sh.setFrozenRows(1);
  sh.setColumnWidth(1, 200);
  sh.setColumnWidth(3, 120);
  sh.setColumnWidth(4, 180);
  sh.setColumnWidth(5, 180);
  return sh;
}
function logError_(action, err) {
  try {
    const sh = getLogSheet_();
    sh.appendRow([new Date(), action, String((err && err.message) || err)]);
  } catch (e) {}
}
function setupSheets() {
  const ss = getSS_();
  const def = ss.getSheetByName('Sheet1') || ss.getSheetByName('ورقة1');
  if (def && def.getLastRow() === 0 && ss.getSheets().length === 1) ss.deleteSheet(def);
  getUsersSheet_();
  getPagesSheet_();
  getLogSheet_();
  SpreadsheetApp.getUi().alert('✓ تم إعداد الأوراق بنجاح — يمكنك الآن النشر كـ Web App.');
}

٤ انشر الخادم كـ Web App ~ ٩٠ ثانية · الأهم

  1. في أعلى يمين المحرر، اضغط زر Deploy (نشْر) ← اختر New deployment.
  2. بجانب كلمة «Select type» اضغط أيقونة الترس ⚙️ ← اختر Web app.
  3. املأ الحقول كالتالي بدقة:
    Description: Hafiz Sync API
    Execute as: Me (أنا)
    Who has access: Anyone (أي شخص)
  4. اضغط Deploy. قد يطلب منك Google Authorize access — اضغط:
    • اختر حسابك.
    • إن ظهرت شاشة «Google hasn't verified this app» — اضغط Advanced ثم Go to Hafiz Backend (unsafe). هذا طبيعي لأنك أنت المطوّر.
    • اضغط Allow (السماح).
  5. بعد نجاح النشر ستظهر نافذة فيها حقل Web app URL — انسخه (يبدأ بـ https://script.google.com/macros/s/...).

٥ اربط الأداة بالخادم ~ ٣٠ ثانية

  1. افتح ملف index.html في متصفحك (بالنقر المزدوج عليه).
  2. اضغط أيقونة ⚙️ الإعدادات في أعلى الصفحة.
  3. الصق Web App URL الذي نسخته في الحقل الأول.
  4. اضغط اختبار الاتصال. يجب أن تظهر رسالة خضراء: ✓ الاتصال ناجح.
  5. اضغط حفظ — انتهى! 🎉
✨
الآن سيبدأ التطبيق بمزامنة تقدمك تلقائياً كل ٣ دقائق. يمكنك أيضاً الضغط على أيقونة 🔄 في الأعلى للمزامنة الفورية.

✓ تحقق سريع: هل كل شيء يعمل؟

ما يجب أن تراه النتيجة المتوقعة
اضغط «اختبار الاتصال» في الإعدادات ✓ الاتصال ناجح
أيقونة 🔄 في الترويسة (بجانب كلمة «محلي») تتحول إلى «متزامن» بالأخضر
افتح جدول Google Sheets تظهر أوراق Users و Pages و SyncLog
علّم صفحة جديدة في الأداة ثم زامن يظهر صف جديد في ورقة Pages
افتح نفس الرابط من جهاز آخر تظهر نفس بياناتك بعد المزامنة

؟ أسئلة شائعة

🔴 «اختبار الاتصال» يفشل دائماً
تحقق من ثلاث نقاط:
١. هل اخترت Who has access: Anyone عند النشر؟ (أكثر سبب شيوعاً)
٢. هل الرابط ينتهي بكلمة /exec وليس /dev؟
٣. جرّب فتح الرابط مباشرة في المتصفح — يجب أن ترى {"ok":true,...}. إن ظهرت رسالة خطأ، أعد النشر من البداية.
🟡 بياناتي لا تظهر على الجهاز الآخر
تأكد من:
• تسجيل الدخول بنفس اسم المستخدم بالضبط (حساس لحالة الأحرف الكبيرة/الصغيرة).
• الضغط على 🔄 «مزامنة الآن» يدوياً في الجهاز الثاني.
• انتظار ٣ دقائق على الأقل — أو تفعيل المزامنة التلقائية من الإعدادات.
🔵 هل بياناتي آمنة؟
نعم — البيانات تُخزَّن في جدولك الخاص على Google Drive، ولا يصل إليها أحد غيرك. الأداة تتصل مباشرة بـ Google ولا تمر عبر أي خادم وسيط.
ملاحظة: الأداة لا تُرسل كلمة السر PIN إلى الخادم — التحقق منها يتم محلياً على جهازك فقط.
🟠 هل يمكن استخدامها بدون إنترنت؟
نعم بامتياز. الأداة تعمل بكامل طاقتها بدون اتصال وتحفظ كل شيء في متصفحك. عندما يعود الاتصال، ترفع كل التغييرات المعلّقة تلقائياً إلى Google Sheets.
🟣 كيف يشارك أصدقائي نفس المجموعة؟
كل ما عليهم فعله:
١. فتح نفس ملف index.html.
٢. إدخال نفس رابط Web App URL في الإعدادات.
٣. إنشاء حساب باسمهم الخاص (PIN خاص بهم).
بعدها سيظهر الجميع في تبويب «المجموعة» ويمكن تسميع بعضكم البعض.
⚫ نسيت أن أضغط Deploy بعد تعديل الكود
التعديلات لن تُطبَّق حتى تنشر New version. اذهب إلى Deploy ← Manage deployments ← أيقونة ✏️ ← Version: New version ← Deploy. الرابط لن يتغير.
⚪ هل يمكن حذف البيانات والبدء من جديد؟
من داخل الأداة: الإعدادات ← «حذف كل البيانات المحلية».
لحذف البيانات السحابية: امسح الصفوف من أوراق Users و Pages في Google Sheets.
